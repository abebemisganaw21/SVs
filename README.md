Multilineage Pedigree Analysis: Structural Variant Inheritance and Phenotypic Analysis

Overview

This repository contains data files and analysis scripts supporting research on structural variants (SVs), inheritance patterns, and phenotypic variation in a multilineage pedigree.

The repository is intended to support transparent, reproducible genomic data analysis and visualization.

Research Objectives

The analysis aims to:

Characterize structural variant inheritance patterns across pedigree lineages.

Investigate de novo structural variants and their distribution.

Analyze phenotypic variation among samples or lineages.

Visualize genomic variation and inheritance patterns.

Support the identification of candidate variants potentially associated with phenotypic traits.
